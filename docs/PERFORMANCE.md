# 后台资源占用优化（2026-10-31）

## 条件与方法

- Mac mini M4、16 GB 内存、macOS 27.2，Meridian 使用 Release 构建。
- Meridian 五项功能、五个菜单栏小组件均开启，5K HiDPI 镜像保持开启。
- 系统监控后台间隔保持 2 秒，风扇采样保持原设置；没有通过停用功能或降低采样频率换取结果。
- 统计时关闭 Meridian 主窗口与弹窗，没有截图、录制或主动滚动。
- 使用系统 `top` 按 2 秒间隔采样 CPU 与 physical footprint，排除第一帧的累计值。修改前 7 个有效样本、14 秒；修改后 15 个有效样本、30 秒。
- 内存使用 physical footprint，并用 `vmmap -summary` 交叉核对，不能与 RSS 或虚拟地址空间混用。
- 本机只有 Command Line Tools，没有 `xctrace`。调用栈使用系统 `sample`，没有取得 SwiftUI Instruments 的 Cause & Effect Graph。

## 结果

| 应用/阶段 | CPU 平均 | CPU 范围 | 内存 |
| --- | ---: | ---: | ---: |
| Meridian 修改前 | 3.50% | 2.8%–4.8% | 92–93 MB |
| Meridian 修改后，使用界面后关闭 | 1.55% | 0.9%–2.1% | 81–83 MB |

本次后台 CPU 均值下降约 56%。`vmmap` 核对的 Meridian physical footprint 为修改前 92.4 MB、修改后 81.0 MB。
优化版刚启动、未打开主窗口时还测到约 54 MB；这不能直接与已经使用过界面的数值比较。

以上是不同时间段、本机当前工作负载下的观测，不是严格控制环境的基准测试。系统负载、内存压缩和界面使用历史会影响结果。
打开监控详情、截图或录制时的 CPU 和峰值内存不适用这张后台表。本文结果来自模块收进仓库之前的性能构建，不能视为新版本的重新测量。

## 定位与修改

1. 隐藏的控制中心预先挂载整棵 SwiftUI 视图，模型采样仍会触发布局。修改前后台 `sample` 采到了 `NSHostingView.layout`、
   `ViewGraph`、`AttributeGraph` 与布局调用。现在只在弹窗显示期间挂载内容，关闭后移除其模型订阅。
2. 主窗口关闭后原来保留完整页面。现在保留窗口与导航状态，关闭时卸载页面；重开时重新挂载。
   这也让监控详情的 `onDisappear` 能结束高频采样与进程排行请求。
3. 原来每次采样都创建和替换所有相关状态栏图像。现在缓存每个小组件实际显示的文本与布局，显示内容变化时才生成图像；
   缓存上限为现有小组件数量，移除小组件时同步清理。
4. 原来的 `$snapshot` / `$reading` 回调忽略了发布值，转而读取尚未完成赋值的模型属性，菜单栏数值会落后一拍。
   现在直接使用回调中的新值生成展示内容。
5. 滚动模块状态每 2 秒轮询时，原来即使值相同也发布三次 `@Published` 更新。现在只发布真正变化的值，
   并为状态轮询增加 0.5 秒 timer tolerance，允许系统合并唤醒。

修改后的后台 6 秒调用栈采样中没有再次采到 SwiftUI 布局或进程排行扫描；主要剩余活动是菜单栏图像更新与常规采样。
这支持隐藏界面更新已减少，但低频调用仍可能被采样遗漏，不能把调用栈缺席解释为严格的调用次数证明。

## 验证

- `scripts/build-app.sh release` 与 `codesign --verify --strict --deep` 通过。
- 主窗口的系统监控图表、每核数值、内存、网络、磁盘与进程排行可见；关闭后重新打开能恢复页面。
- CPU 弹窗、风扇详情、控制中心主页，以及主页进入 CPU 详情均可正常显示。
- 关闭全部界面后用 CoreGraphics 窗口列表确认 Meridian 没有可见窗口，再进行后台复测。
- 5K HiDPI 会话和菜单栏数据继续工作。

原始采样、构建日志和修改前源码备份保存在本机 `.build/performance/`。

## 2026-11-01 采样与 OCR

- 系统基础采样和进程排行改为两个独立串行队列。磁盘/网络速率先发布，`proc_pid_rusage` 与 `nettop` 不再阻塞基础数据。
- `nettop` 只在网络详情可见时运行，每 2 秒一次；首次打开会用短差分基线立即给出排行。关闭面板后没有残留 `nettop` 进程。
- 网络面板增加主接口累计上传/下载、出口公网 IP、地区/国家代码和运营商；公网查询只在网络详情打开时执行并缓存。
- OCR 改用 VisionKit 系统文字分析，5K 截图先缩到最长边 3600 像素；Vision 多语言请求仅作为回退。没有在应用启动时常驻预热。
