# 新图标候选：系统工具箱

候选保存在 `Resources/IconDesign/`，由 `scripts/make-icon-v2.swift` 使用原生路径绘图生成，不依赖字体文件或外部图片。

- 金属箱体与提手：把截图、显示、滚动、温度和监控装进同一个工具箱。
- 橙色搭扣与横向轨道：既是箱扣，也暗示系统调节滑块。
- 三根阶梯形刻度：表达监控和状态，作为大尺寸下的次级细节；小尺寸版本省略它。
- 深青色底与银色箱体：与原来的四宫格区分，缩小后仍依靠工具箱轮廓辨识。

产物包括 1024 像素 PNG、标准 iconset 与 ICNS。候选尚未替换当前构建图标，也没有改变菜单栏的单色图标。
