# Meridian 使用手册

[简体中文](USER_GUIDE.md) · [English](USER_GUIDE.en.md)

本手册对应当前源码功能。正式下载包的架构、签名与已知问题，以对应 Release 的说明为准。

## 第一次使用

1. 将应用放进“应用程序”并打开，菜单栏会出现 Meridian 主图标。
2. 打开主窗口的“通用”，选择所需功能与菜单栏数据小组件。
3. 在对应功能页请求权限，按系统提示授权。
4. 返回应用检查状态。部分系统权限需要退出并重新打开应用后生效。

外观提供“跟随系统 / 浅色 / 深色”。选择“跟随系统”后，应用使用 macOS 当前外观；选择浅色或深色则覆盖应用自己的外观。

## 菜单栏与主窗口

| 操作 | 结果 |
| --- | --- |
| 左键主图标 | 打开控制中心 |
| 左键 CPU、内存、网速等小组件 | 打开对应详情 |
| 右键主图标 | 显示快捷操作菜单 |
| 点击面板顶部 Meridian | 返回控制中心首页 |
| `⌘,` | 打开通用设置 |
| 关闭主窗口 | 保持菜单栏运行 |
| 菜单选择“退出 Meridian” | 完全退出并请求恢复硬件控制状态 |

## 截图、识字与贴图

- **区域截图**：按 `⌘⇧2`，拖选后使用选区工具条进行标注、复制、保存、贴图或识字。
- **截图识字**：按 `⌘⇧1`，拖选文字区域，松开鼠标后使用本机文字识别。
- **截图贴图**：从控制中心点击贴图，或在设置中配置快捷键。选区会固定显示在屏幕上。
- **其他截图**：截图页提供全屏、当前窗口、上次区域与 3 秒延时入口。
- **历史记录**：截图页或菜单栏右键菜单打开历史；设置中可调整保留数量、保存位置和输出尺寸。
- **贴图管理**：截图页可全部显示、隐藏或关闭当前贴图。
- **取消**：选区时按 `Esc`。

截图历史会保存在本机。不要在公开的问题反馈中直接附上含私人信息的截图。

## 录制 GIF

1. 按 `⌥⇧G` 或点击控制中心的 GIF 按钮。
2. 选择要录制的区域并开始。
3. 再按一次快捷键，或使用屏幕上的停止按钮结束。

最长录制 30 秒。帧率和最大宽度在截图页调整，降低这些参数能减小文件大小及编码开销。

## 显示器

显示器页提供每块显示器可用的亮度、分辨率、刷新率和 HDR 控制。外接屏 DDC 能力受显示器、线材、转接器与连接方式影响。

- **亮度**：优先使用设备支持的控制方式；软件调暗改变显示输出，不能替代屏幕背光调节。
- **分辨率**：默认只列出与面板同比例的 HiDPI 档（例如 2560×1440 面板的 1280×720 到 2880×1620），直接在物理屏上渲染，不经过虚拟屏，HDR 与高刷新率都保留。打开“显示全部模式”可看到系统报告的全部模式。
- **刷新率**：单独切换，分辨率不变；切换前处于 HDR 的，切换后若掉出 HDR 会自动重新打开。
- **HiDPI 档位**：为外接屏写入系统显示覆盖，补齐中间尺寸的 HiDPI 档；需要管理员助手，重新插拔显示线或注销后生效。
- **HDR**：HDR 模式下亮度滑块改为调节 macOS 的 SDR 亮度（与控制中心的 HDR 亮度相同），不再用 DDC 和软件调暗，避免截断 HDR 高光；“亮度提升”可利用 HDR 余量把 SDR 画面提亮到 100% 以上。可选在 HDR 时自动关闭夜览和原彩显示。
- **恢复原生**：回到面板原生尺寸（有 HiDPI 档时用 HiDPI），保持当前刷新率。
- **F1/F2**：在显示器页开启亮度键接管，必要时授予输入监控权限。
- **虚拟屏**：可选 HDR（Display P3 + PQ），镜像或录制到 HDR 屏时保留 HDR 内容。

出现黑屏、闪烁或窗口重排时，优先恢复原生模式、关闭相关显示功能并检查连接。请勿同时让多个工具持续写同一显示器的亮度或色表。

## 风扇与温度

温度与转速可在菜单栏和详情页查看。当前温度目录是内置候选集，名称及机型语义尚未全部验证；无法读取的项目不会构成完整的硬件诊断。

| 模式 | 含义 |
| --- | --- |
| 系统自动 | 将风扇交给系统控制 |
| 固定转速 | 在应用允许范围内指定目标 RPM |
| 温度曲线 | 根据所选温度和起始、满速温度计算目标转速 |
| 全速预设 | 使用应用配置的有效最大转速，受最大转速比例限制 |

调整固定转速或温度曲线后，点击“应用”生效。非自动控制需要兼容的风扇硬件以及管理员安装的控制服务。

遇到温度读数缺失、异常或机型不匹配，请使用系统自动。当前助手与温度目录仍有公开发布前的验证事项，见[发布清单](RELEASING.md)。

## 滚动增强

在滚动页配置平滑滚动、反向与按应用例外。可以用菜单栏快捷菜单或自定义快捷键暂停，再恢复时保留参数。

遇到滚动跳动、方向异常或拖动问题，先暂停滚动增强复测；再逐个退出其他处理鼠标事件的应用。暂停某个功能不会删除它的设置。

## 系统监控

菜单栏可显示 CPU、内存、网络、温度和风扇。监控详情提供每核 CPU、内存分类、网络吞吐、磁盘及进程排行。

进程排行只在相关详情可见时请求采样。查看实时排行和录制 GIF 等工作负载会增加资源占用；详情关闭后会撤销对应界面订阅。

## 权限说明

| 权限 | 用途 | 何时需要 |
| --- | --- | --- |
| 屏幕录制 | 截图、识字、GIF | 使用屏幕捕获功能时 |
| 辅助功能 | 滚动增强 | 开启该功能时 |
| 输入监控 | 可选的外接屏亮度键接管 | 系统要求时 |
| 管理员授权 | 风扇控制服务、显示覆盖助手 | 安装或移除对应服务时 |

如果系统权限列表里找不到应用，在功能页选择“在访达中显示 Meridian”，再使用系统设置的添加入口选择应用。授权后可退出并重新打开，检查应用中的权限状态。

## 更新与卸载

更新前停止 GIF 录制，风扇切回系统自动，显示恢复原生，然后退出 Meridian 再替换应用。不同签名身份或临时签名之间的更新可能需要重新授权。

卸载前在应用里停用登录时启动、将风扇切回自动、恢复原生显示，并移除已安装的风扇与显示覆盖服务。再退出应用，将 `Meridian.app` 移到废纸篓。仅删除应用不会自动卸载 root 助手或删除截图历史；服务的完整卸载和升级流程仍列为发布前验证项。

本机数据位置见[隐私说明](PRIVACY.md)。
